# M5Stack Dial V1.1 Study and Development

This project documents, backs up, studies, and incrementally develops firmware for an M5Stack Dial V1.1.

Start with:

- `Project instruction.md` for project rules and key files
- `M5StackDial_Functional Specification.md` for programmable capabilities
- `M5StackDial_AI_Specification.md` for AI-facing device knowledge
- `M5StackDial_ClaudeDesign_Specification.md` for UI/UX design guidance
- `Factory M5Dial_App_Functional Specificaton.md` for the original app behavior
- `Factory M5Dial_App_Programming Specificaton (AI).md` for original-app reproduction
- `M5StackDial_Development Log.log` for evidence, experiments, and decisions
- `backup/README.md` for recovery information

The private repository includes the original 8 MB flash backup together with its recovery instructions and checksum. Verify `backup/SHA256SUMS` before restoration and treat a full-flash write as destructive.
