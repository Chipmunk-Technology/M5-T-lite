# M5Stack T-Lite 熱記憶 — Claude Design Specification

## Purpose

這是熱記憶的介面說明，給之後畫畫面的人用。畫得出人看了會做的三個畫面。

不要在設計產出裡放原始碼、接腳、暫存器或建置步驟。

## Device Character

T-Lite 是一支細長的熱像筆，接在電腦上。電腦網頁才是產品。裝置上的 1.14 吋螢幕只重複網頁已經說出的那一句話。

它不是熱像儀軟體的縮小版。那些軟體從彩虹圖和工具列開始。這裡從一句人話開始。熱圖是證據，放在句子和數字下面。

第一版有三種工作，共用同一套版式：記住資產的熱、找出漏熱的一段、在黑暗裡有暖物經過時響一聲。

## The Only Layout

一屏一件事。字大、留白多、對齊嚴。沒有圖示牆，沒有側邊十個工具，沒有儀表板。

由上到下：

1. 一句結論。完整的句子，用日常的字。
2. 一個大數字，帶單位。
3. 一張熱圖。
4. 一行小字，說明這個數字為什麼可以信，例如這一格大約蓋住多大，或「篩查用，非計量追溯」。

熱圖用單一由冷到暖的色帶。唯一的強調色留給「比上次更熱」和哨兵事件。冷的差異用同一個色相的另一個安靜深淺，不引入第二套彩虹。

熱圖的格子必須看得出來。可以放大到好看的尺寸，放大要標「顯示放大 · 32×24」。不要畫成光滑的照片。

## Three Screens

### 現在

結論例如：「左接點比上次高 11°C。」第一次看這件資產時：「已看到左接點，最高 42°C。」

大數字是這句話裡的那個數。不要同時放最小、最大、平均三個大字。其餘數字進「細節」，第一版可以沒有細節頁。

主按鈕只有一個：「記住這一幀」。名字在記住之前用一個短欄位，預設空白，提示「這是什麼」。

距離是三個字：貼近、一手距離、房間。選過就留在小字裡，不佔主畫面。

材料是四個字：塑膠、塗裝金屬、電路板、水。另有一個狀態句，在選到光亮金屬時取代數字的可信度：「這個表面讀數不可靠。」

### 對上次

左這次，右上次，中間仍是那一句差值。兩張熱圖一樣大，同一色標。不要求人自己找熱點。

沒有自動對齊的控制，因為沒有可見光可以對。小字寫：「把裝置放回上次的位置。」

### 交出去

一頁，可印、可存。順序就是畫面順序：句子、數字、熱圖、小字。小字在這一頁寫全：材料、發射率、反射溫度、距離選項、裝置識別、「篩查用，非計量追溯」。

不要做封面、目錄或多頁分析附錄。

## Leak, Same Layout

結論三選一，系統自己選，人不用切模式選單以外的東西：

- 「這條縫比牆面低 4°C。」大數字是 4。
- 「現在溫差不夠。」大數字留空，熱圖仍在。
- 「牆後可能有一段較熱的管路。」大數字是溫差，小字是「可能」。

標出差異的方式是在熱圖上圈出那段，圈是細線。不蓋住格子。

## Sentry, Same Layout

結論兩句就夠：

- 「守候中。」大數字不顯示溫度，顯示安靜了多久，或留白。
- 「3 分鐘前有暖物經過。」大數字是 3 分鐘，或該次比背景高幾度，二選一，整頁只留一個。優先用時間，因為人要知道的是「剛發生」。溫差放進小字。

靈敏度是三個字：高、中、低。不在主畫面放°C 門檻。

忽略區：在熱圖上拖一個方塊，方塊內的格子變淡，小字寫「這些格子不響」。沒有圖層面板。

事件列表是「交出去」之前的第四個安靜列表，每一行只有時間和那一句話。點進去才看到該幀。不在守候畫面旁邊滾動一排縮圖。

裝置沒有接電腦時，網頁可以不在。裝置螢幕仍顯示「守候中」或「剛剛有暖物經過」。

## Words the Interface May Say

用這些句子的語氣，不另造一套：

- 「請握穩。」
- 「再靠近。這一格蓋住的範圍太大。」
- 「已記住左接點。」
- 「左接點比上次高 11°C。」
- 「這個表面讀數不可靠。」
- 「現在溫差不夠。」
- 「守候中。」
- 「3 分鐘前有暖物經過。」
- 「裝置已卸下。」

不要出現：說謊、緊張、情緒、可疑人員、入侵、警報系統、高精度、醫療。

## The Small Screen

135×240，直向。只放：

- 第一行：連線，或守候
- 中間：與網頁相同的那一句，必要時縮成兩行
- 下面：電量

不放色帶圖例，不放選單，不放 QR code。Button A 在熱記憶時記住一幀；螢幕用「已記住」回一句，然後回到結論。

## Colour and Type

- 底是暖白或近黑二選一，整套產品只選一個。字是另一個。
- 熱圖色帶連續、單向。低溫一端安靜，高溫一端才深。
- 強調色只用在「比上次更熱」和哨兵事件的那一句。
- 字體是普通的無襯線。結論最大，數字次之，小字最小但仍清楚。
- 單位寫在數字旁，例如 `11°C`、`3 分鐘`。

## States

每個畫面都要有：尚未連接、正在看、請握穩、請靠近、已記住、比上次更熱、守候中、剛剛經過、裝置卸下。

卸下之後不要留著最後一幀假裝還在看。句子改成「裝置已卸下」，熱圖變淡。

## What Not to Draw

- 彩虹熱圖、交叉游標工具列、六個同時出現的 ROI 框
- 儀表、環形圖、即時折線放在第一屏
- 光滑插值成照片的熱圖
- 人臉特徵點、身份、情緒標籤
- 裝置螢幕上的多層選單
- 任何看起來像防盜主機的紅燈與「ALARM」

## Second Wave, Not in the First Pictures

冷卻時鐘、熱足跡、在席人數、金樣板、液位、揮手、縮時、熱尋寶。若之後要畫，仍用本檔的同一版式，不新增工具列。
